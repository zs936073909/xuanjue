# 玄决 · 传统术数决策辅助 App

> 实时大六壬时课 + P1 术数模块（小六壬 / 梅花易数 / 六爻 / 塔罗 / 八字）+ AI 深度解读

## 下载安装

**安卓手机直接安装**（无需电脑、无需编译）：

👉 前往 [Releases 页面](https://github.com/zs936073909/xuanjue/releases)，下载最新的 `app-debug.apk`，传输到手机后点击安装。

**安装前需开启**：手机设置 → 安全/应用管理 → 允许「安装未知来源应用」。

> 首次安装可能提示"风险应用"（debug 签名），确认继续即可。

## 功能特性

- **实时决策台**：自动起课，当前时辰大六壬盘面 + 宜忌 + 值神 + 建除 + 冲煞
- **问事向导**：5 步流程（类型 → 背景 → 起课 → 术数 → 结果）
- **大六壬排盘**：天盘四课、三传、神煞、格局、类神（昼夜贵人、涉害取深、中气定将）
- **P1 术数模块**：小六壬、梅花易数、六爻、塔罗、八字（统一接口，多盘交叉摘要）
- **AI 深度解读**：用户自带 Key，支持 OpenAI / DeepSeek / 通义 / Kimi / 智谱 / Ollama / 中转站等
- **案例库**：localStorage 本地存储，复盘提醒、统计准确率、备份导入导出
- **离线优先**：核心算法全本地，无网络也能起课

## AI 配置说明

进入「我的 → AI 模型配置」：

1. **提供商**：从 12 个预设中选（含 Ollama 本地开源方案）
2. **API Key**：用户自带，应用不内置任何密钥
3. **协议**：OpenAI 兼容（推荐）/ Anthropic
4. **测试连接**：配置后点测试按钮验证可用性

密钥默认不导出，备份文件安全；密钥明文存于本机 localStorage，请勿在共享设备保存。

## 技术栈

- 前端：原生 HTML/CSS/JS（无框架），PWA 支持
- 移动端：Capacitor 6 + Android SDK 34
- 构建：Gradle 8.2.1，应用 ID `cn.xuanjue.app`
- 测试：47 项核心单元测试 + 45 项 DOM 端到端测试
