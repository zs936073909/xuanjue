# 玄决 · 以传统术数为文化视角的个人工具

> 帮你梳理问题、记录判断、回看决策。不预测现实，也不替你做决定。

## 它解决的问题

大多数人带着"该不该"走进术数，但真正卡住的往往是：问题没问清、选项没摊开、担心的东西没说出来。

玄决把这条链路拉直：

**问事 → 问题卡 → 起一课 → 三层结果 → 留下你自己的判断 → 到期回来复盘**

术数在这里是「一种有出处的传统视角」，不是「一个替你拍板的答案」。

## 三条产品原则

1. **结果分三层，不许揉成一句结论**
   - 盘面事实：算法算出了什么，逐项可核对；
   - 传统解释：这套体系依据哪条规则、为什么这么看，附依据标签；
   - 反思提示：你自己的判断、还需要核实的现实信息。
2. **多术数并列，不做投票**：大六壬、六爻、梅花、小六壬、塔罗、奇门依据各不相同，并列看看即可，不能当独立证据相互验证。
3. **不做命中率**：复盘只问三件事——事情发生了吗、当时的依据有用吗、你行动了吗。它帮你看清自己的判断习惯，不是给预测能力盖章。

## 功能

- **问事与问题卡**：一句话即可起课；愿意多想两分钟，可展开"在什么之间选 / 什么时候要定 / 能控制什么 / 最担心什么 / 还有什么没核实"。
- **三层结果页**：事实 / 传统解释 / 反思，分隔清晰，各自独立成立。
- **判断与行动**：记录当时倾向、打算做什么、预期看到什么信号、计划何时复盘。
- **复盘**：到期提醒；三问式复盘，不统计"准不准"。
- **本机档案**：记录只存浏览器 localStorage，可单条或全部导出 JSON。
- **重大话题伴随提示**：涉及健康、资金、法律时，固定提示以专业意见为准；不阻断提问，也不藏在页脚。
- **多术数视角**：大六壬（四课三传 / 天地盘 / 课体格局）、六爻（铜钱摇卦）、梅花易数、小六壬、塔罗（韦特真牌）、奇门遁甲。
- **命盘与合婚**：八字四柱 + 紫微斗数（含真太阳时、格局识别）；合婚七维参考，分值明确标注为规则加权参考值。
- **典籍**：十四部公版典籍本地全文检索，按法门分类，标注出处。
- **离线优先**：核心算法全部本地，无网络也能起课。
- **夜盘**：用真实时课生成的 3D 小游戏，十二宫、天将、三传都来自本机起课。

## 下载安装

**安卓手机直接安装**（无需电脑、无需编译）：

前往 [Releases 页面](https://github.com/zs936073909/xuanjue/releases)，下载最新的 `app-debug.apk`，传输到手机后点击安装。

**安装前需开启**：手机设置 → 安全/应用管理 → 允许「安装未知来源应用」。

> 首次安装可能提示"风险应用"（debug 签名），确认继续即可。

网页端由 `server/` 托管 `webapp/`，手机与桌面访问同一套自适应界面。

## AI 配置

AI 只负责解释术语、追问和整理信息，不负责把不确定判断包装成确定答案。

在「命盘问对」或「此刻问对」面板右上角点连接状态即可配置：

1. **云令牌**：自动注册或粘贴已有令牌；
2. **API Key**：用户自带，应用不内置任何密钥；
3. **模型**：由服务端按场景（实时 / 命盘 / 典籍）选择档位，客户端可覆盖。

密钥明文存于本机 localStorage，默认不导出，请勿在共享设备保存。

## 目录

```
webapp/            网页端（无构建，静态直发）
  index.html
  css/app.css
  js/ui.js         视图与交互
  js/decision.js   问事档案数据层（迁移 / 到期 / 统计 / 导出）
  js/engines/      排盘引擎（与 APK 端同源同算）
server/            静态托管 + AI 代理（Render）
www/               Capacitor 打包源，构建 APK 用
data/              典籍与城市经度库
android/           Capacitor Android 工程
```
